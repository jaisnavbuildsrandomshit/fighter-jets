# Fighter Jets

A cinematic presentation: seven aircraft, twenty seconds each.

**Live:** https://jaisnavbuildsrandomshit.github.io/fighter-jets/

Every transition is a tracking shot. The camera whip-pans in the direction the next jet is flying; the sky streaks past with motion blur and settles into the real photo, while the jet itself (cut out of its own photo) stays sharp, afterburners lit, and lands exactly where it sits in the shot. Clouds whip past the lens, the frame shakes, and a synthesized jet roar dopplers across the speakers. Tactical callouts then lock on to each jet's special features.

## Controls

| Key | Action |
|---|---|

| M | Sound on/off |
| N | Speaker notes |
| F | Fullscreen |
| Home | Back to the start |

Start at a given scene with `#N` in the URL (for example `#4` for the F-22).
