# Fighter Jets

A cinematic presentation: seven aircraft, twenty seconds each.

**Live:** https://jaisnavbuildsrandomshit.github.io/fighter-jets/

Every jet is real footage: the clip plays, slows into a speed ramp and slams to a freeze frame, then tactical callouts lock on to its special features. Scenes hard-cut from one jet to the next, with no sound. Jets with no usable free footage (Su-57, F-14, F-117) use close-up photos.

## Controls

| Key | Action |
|---|---|
| Click / any key | Start (from the black ready screen) |
| → / Space / click | Next scene |
| ← | Previous scene |
| P | Pause or resume the 20-second timer |
| N | Speaker notes |
| F | Fullscreen |
| Home | Back to the start |

Start at a given scene with `#N` in the URL (for example `#4` for the F-22).
