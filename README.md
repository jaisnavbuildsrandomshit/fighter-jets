# Fighter Jets

A fly-through presentation: seven aircraft, twenty seconds each. A real F-22 flies across the screen between scenes and the next aircraft opens in its wake. Tactical callouts lock on to each jet's special features.

**Live:** https://jaisnavbuildsrandomshit.github.io/fighter-jets/

## Controls

| Key | Action |
|---|---|
| → / Space / click | Next scene |
| ← | Previous scene |
| P | Pause or resume the 20-second timer |
| F | Fullscreen |
| N | Speaker notes |
| Home | Back to the start |

Move the mouse (or tilt a phone) and the photo, clouds and text shift at different depths, like looking through a window.
